# Unity AI — Behaviour Tree Editor

Student project exploring **AI systems in Unity** with a custom **behaviour tree editor** built in UI Toolkit.

## What I built

- Visual behaviour tree editor (graph view, node controls, brain editor)
- AI tooling for designing and iterating on agent logic in-editor
- Unity C# gameplay and editor scripting

## Tech

- Unity (C#)
- UI Toolkit / custom editor windows
- Behaviour trees

## How to open

1. Clone the repository
2. Open the `Assignment` folder as a Unity project
3. Explore scenes and `Assets/Editor/AI/` for the editor implementation

## Note

This repo contains **source only**. Unity `Library/` and local cache folders are not tracked.
